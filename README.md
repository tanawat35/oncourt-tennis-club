# On Court Tennis Club — เว็บไซต์ 3 มิติ + ระบบจอง + แต้มสะสม

เว็บไซต์ของ **On Court Tennis Club** สนามเทนนิสในร่มแห่งแรกและแห่งเดียวในจังหวัดอุตรดิตถ์ และโค้ชมาร์ค (Worradit Pathamarot, ITF Level 1 Coach)

- ฉาก 3 มิติคอร์ตในร่ม เล่าเรื่องด้วยการเลื่อนหน้าจอ (Three.js + GSAP + Lenis)
- จองคอร์ต จองเรียน สมัครสมาชิก พร้อมกันจองซ้อน
- **แต้มสะสม On Court Points**: ทุก 10 บาท = 1 แต้ม เมื่อโค้ชยืนยัน, สมาชิกใหม่รับ 50 แต้ม, 4 ระดับ (Rookie → Champion) ได้แต้มเพิ่มตามระดับ, แลกรางวัลที่เคาน์เตอร์
- หน้าโค้ช `#admin`: ยืนยัน/ยกเลิกการจอง ตารางรายวัน อนุมัติสมาชิก ให้/หัก/แลกแต้ม
- ภาษาไทย/อังกฤษ รองรับมือถือ และโหมดลดการเคลื่อนไหว

## เปิดดูบนเครื่อง
ดับเบิลคลิก `OnCourt-preview.html` (ต้องอยู่คู่กับโฟลเดอร์ `public/`) · หน้าโค้ช: ลิงก์ "สำหรับโค้ช" ท้ายเว็บ · PIN เริ่มต้น `2026`

> บน GitHub Pages และไฟล์ preview ระบบจองเป็น **โหมดทดลอง** (ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน) ถ้าจะรับจองจริงจากลูกค้าทุกคน ให้รันเซิร์ฟเวอร์ `npm start` บนโฮสต์ที่รัน Node ได้ (เช่น Render, Railway)

## แก้ข้อมูลธุรกิจ
ทุกอย่างอยู่ใน `src/content.js` — ค่าที่เขียน `SAMPLE` คือค่าตัวอย่าง (ราคา เวลาเปิด จำนวนคอร์ต กติกาแต้ม รางวัล)
- ใส่ `promptpay: '08xxxxxxxx'` เพื่อให้หน้าจองแสดง QR พร้อมยอดเงิน
- เปลี่ยน `adminPin` ก่อนใช้งานจริง (บนเซิร์ฟเวอร์ใช้ตัวแปร `ADMIN_PIN`)
- รูปและวิดีโออยู่ใน `public/media/`

## สำหรับนักพัฒนา
```bash
npm install
npm run dev                  # พัฒนา http://localhost:5173
npm run build && npm start   # เซิร์ฟเวอร์จริง + API จอง/แต้ม http://localhost:3000 (ข้อมูลใน server/data.json)
npm run build:preview        # สร้าง OnCourt-preview.html สำหรับดับเบิลคลิก
```
ชั้นข้อมูล `src/store.js` เลือกที่เก็บอัตโนมัติ: เซิร์ฟเวอร์ของเราเอง → ฐานข้อมูล claude.ai Artifact → เบราว์เซอร์ (ทดลอง)

โครงสร้าง: `src/scene.js` ฉาก 3 มิติ · `src/main.js` การเลื่อนเล่าเรื่องและส่วนต่าง ๆ · `src/booking.js` ระบบจอง · `src/admin.js` หน้าโค้ช · `src/store.js` ข้อมูล/กันจองซ้อน/แต้ม · `server/server.js` API ไม่ต้องติดตั้งเพิ่ม · `tests/` สคริปต์ทดสอบ Playwright
